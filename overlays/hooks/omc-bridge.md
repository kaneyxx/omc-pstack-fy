# omc-pstack-fy bridge for oh-my-claudecode

omc-pstack-fy's hook adds this while oh-my-claudecode (OMC) is installed and enabled. For agent choices inside OMC workflows, it overrides OMC's CLAUDE.md block ("Route code to `executor`") and OMC's skill text, including the literal `oh-my-claudecode:executor` spawn examples. The Skill tool refuses poteto-mode and interrogate, so Read each SKILL.md named here and follow it.

- **Code work.** Where OMC would spawn `executor`, `debugger` (alias `build-fixer`), `designer`, `code-simplifier`, or a `test-engineer` that writes tests, spawn `subagent_type: "omc-pstack-fy:poteto-agent"` instead. Name the poteto-mode playbook: Feature, Bug fix, or Refactoring for `executor`, Bug fix for `debugger`, Feature for `designer`, Refactoring for `code-simplifier`, and the tested change's playbook for `test-engineer`. Put {{skill:poteto-mode}} in the prompt.
- **Delegate end state.** Tell the delegate it runs inside an OMC workflow. It runs only the playbook's code steps, skips commit, push, and the Opening a PR playbook, and returns its diff and evidence to the OMC lead. In a team, it also follows team's worker protocol: it claims and completes its task on the task list and reports to `team-lead` by message.
- **Final code review.** Only at a workflow's final review gate, where OMC would run `code-reviewer` or its review skill (autopilot Phase 4, the team-verify pass before team completes, ultragoal's final `codeReview`, an execute hand-off to review), Read and run {{skill:interrogate}} beside OMC's own review, which still covers the structure and maintainability interrogate skips. Earlier passes skip interrogate, because it costs more. The stricter verdict wins. For interrogate, no verified findings, or each one fixed and its command rerun clean, count as `APPROVE`. An open verified finding counts as `REQUEST CHANGES`, and one caused by the design leaves the architect status not `CLEAR`.
- **Deslop.** ralph step 7.5 and ultragoal's `aiSlopCleaner` gate run {{skill:deslop}} on the workflow's changed files, in place of `ai-slop-cleaner`.
- **OMC keeps** ralph's Step 7 architect or critic check and its `verifier`, which verify the work is done, not review code. It also keeps planning, interviews, goals, the wiki, the notepad, project memory, and its other reviewers.
